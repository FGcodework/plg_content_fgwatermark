What you are looking at

  • The sample images were produced by the plugin's own engine, the same code that runs on a Joomla site – not a mock-up.
  • Originals are never modified. The watermark is applied to a cached copy, and the article's image address is swapped for it when the page is rendered.
  • Links that point straight at an image (the "full size" link of a lightbox) get the watermarked copy too.
  • Image logo (PNG, JPG, GIF or SVG), text, or both; nine positions; opacity and margin for each layer.
